## 逐页文稿

### P01 · 封面

**画面**
- 大标题：**口播场记**
- 副标题：本机短视频口播生产线
- 一行小字：录音 / 贴文 → 转写 → AI 改稿 → 配音或提词器 → 9:16 / 16:9 MP4
- 右下角：不自动发布 · 数据不出本机（可选）

**口播**
> 做短视频口播，最烦的不是拍，是流程碎：录音、转写、改稿、配音、排版、导出，来回切五六个工具。  
> 今天介绍的项目叫「口播场记」——把这条生产线收进一个本机应用里。

---

### P02 · 痛点：口播制作有多碎

**画面（左痛点 / 右后果）**
- 录音在 A，转写在 B，改稿在 ChatGPT，配音又一个站，剪辑再开剪映  
- 文案版本对不上、音色反复试、竖屏横屏各做一遍  
- 素材和 Key 散落各处，隐私也不放心

**口播**
> 典型场景：你刚录完一段想法，想发到抖音或视频号。  
> 结果要：上传转写 → 复制到大模型改成口播稿 → 再找 TTS → 再进剪辑软件贴字幕和封面。  
> 中间任何一步改了文案，后面全部重来。这不是创意问题，是流水线问题。

### P03 · 产品一句话

**画面**
- 居中大字：  
  **录音、音视频或原文进来 → 本机跑完 → 导出 MP4**
- 三个关键词胶囊：本地优先｜人工终审｜不代发

**口播**
> 口播场记的定位很简单：本机短视频口播生产线。  
> 你把录音、音视频，或者直接贴一段口播原文丢进去；系统完成本地转写、可选 AI 改稿，再走 AI 配音或提词器出镜重录，最后用 Remotion 导出 9:16 或 16:9 的成片。  
> 发布页只帮你核对，不替你发到平台。

---

### P04 · 五步流水线总览

**画面（横向五步）**

```
输入 → 原文 → 口播稿 → 成片 → 发布核对
```

| 步骤 | 你做什么 |
| --- | --- |
| 输入 | 录音 / 上传音视频 / 贴文 |
| 原文 | 确认转写结果 |
| 口播稿 | 选体裁与平台，AI 改稿或跳过；可生成展示稿 |
| 成片 | AI 配音，或提词器出镜 |
| 发布 | 检查清单 + 标题简介标签，人自己去发 |

**口播**
> 界面上就是五步。  
> 第一步输入素材；第二步确认转写原文；第三步按体裁和平台改成口播稿，也可以跳过 AI；第四步成片——配音或你自己对着提词器重录；第五步发布核对，系统给检查清单和文案包，账号还是你自己登平台发。

### P05 · 成片两条路

**画面（对比表）**

| | AI 配音 | 提词器重录 |
| --- | --- | --- |
| 声音 | Edge-TTS / Spark 音色克隆 | 你出镜录像抽音 |
| 画面 | 主题色 / 背景图视频 + 步骤卡 + CTA | 出镜画面叠步骤卡和 CTA |
| 适合 | 高效量产、不出镜 | 真人信任感、账号人设 |

**口播**
> 成片故意做成两条路，而不是 whu 一种模板。  
> 要效率：走 AI 配音，微软 Edge 音色，或本机 Spark 克隆你的声音，再配主题、背景和 BGM。  
> 要真人感：打开提词器，对着定稿口播出镜，成片只叠步骤卡和行动号召，不再走 TTS。  
> 一条生产线，两种内容策略。

### P07 · 核心能力清单

**画面（六宫格或图标列表）**
1. **本地转写** — faster-whisper（安装包可内置 base）  
2. **AI 改稿** — OpenAI 兼容（DeepSeek / 通义等），不配 Key 也能规则兜底  
3. **双通道配音** — Edge 在线音色 + Spark 本机克隆  
4. **提词器出镜** — 定稿驱动重录  
5. **Remotion 成片** — 9:16 / 16:9，步骤卡与 CTA  
6. **本地资产库** — 声音 / 文稿 / 成片 / 素材，数据在 `data/`

**口播**
> 能力上可以记六个点：本地 Whisper 转写；可插大模型改稿；Edge 和 Spark 两条配音；提词器真人重录；Remotion 导出成片；以及任务和素材全落本地，没有强制云端账号体系。

### P08 · 本地架构（硬核页）

**画面**

```
浏览器 / Electron (:5288)
        │  /api
        ▼
   FastAPI (:8777)
        ├ faster-whisper 转写
        ├ LLM 改稿（配置页多套 Key）
        ├ Edge-TTS / Spark-TTS
        └ Remotion → MP4
```

- 无数据库：JSON + 文件  
- 绑定 `127.0.0.1`，不是 SaaS  
- 国内镜像友好（pip / npm / 模型下载）

**口播**
> 给喜欢看底层的同学一句话：前面是 Vite + React，可套 Electron；后面是 FastAPI；长任务后台跑、前端轮询。  
> 转写、配音、渲染都在你机器上串起来。没有数据库，设置和任务就是本地文件。  
> 所以它更像「个人工位上的产线」，不是多租户云服务。

### P09 · 隐私与边界：不代发

**画面**
- ✅ 大模型 Key 只在齿轮配置里，可多套切换  
- ✅ 发布页 = 风控检查 + 文案包，**人自己发**  
- ✅ 克隆模型走应用内模型商店，按需下载，不硬塞进安装包  
- ❌ 不承诺自动登录抖音/视频号代发

**口播**
> 有两个边界故意画死。  
> 第一，Key 和数据策略偏本地可控：LLM 配在页面里，不往 `.env` 里塞。  
> 第二，不做自动发布——平台风控和账号安全是另一件事，发布页只帮你核对标题、简介、标签和合规检查，真正点发布还是你。

### P10 · 安装与启动（开发者向）

**画面**
- 环境：Python 3.10+、Node 18+、ffmpeg、Whisper 模型  
- 推荐启动：

```
# 终端 1
python -m uvicorn backend.main:app --reload --host 127.0.0.1 --port 8777

# 终端 2
cd web && npm run electron:dev
```

- 也有 Windows / Mac 桌面安装包路线（壳 + 本地引擎）  
- 健康检查：`http://127.0.0.1:8777/api/health`

**口播**
> 开发机两条命令：后端 8777，前端 Electron 或浏览器 5288。  
> 若要给非开发用户，可以打桌面安装包：Electron 壳加本机引擎，Whisper 可内置，Spark 克隆权重按需再下，避免安装包虚胖。
